# Secciones del informe

Cada integrante agrega aquí una sección Markdown con:

- diseño y alcance;
- decisiones técnicas;
- procedimiento reproducible;
- resultados y capturas;
- dificultades y limitaciones;
- contribución individual.

Convención sugerida: `parte-a.md`, `parte-b.md`, `parte-c.md` y `parte-d.md`.
La persona responsable de D consolida estas secciones en el PDF final.
