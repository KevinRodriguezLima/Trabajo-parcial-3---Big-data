# Dashboard Big Data

Dashboard web para monitorear los eventos, productos, regiones, audiencias y alertas del proyecto de Big Data.

## Development

Necesitas Node.js y npm, o Bun si prefieres usar el lockfile incluido.

```sh
npm i
npm run dev
```

Con Bun:

```sh
bun install
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
